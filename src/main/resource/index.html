Resources are assigned automatically whenever an emergency is reported, a resource is added or freed, and every 30 seconds. Nearest available units go to the most urgent emergencies first.

System information

Application: CrisisFlow

Backend: Java HTTP server

Database: MySQL — crisisflow_v2

Place search: OpenStreetMap Nominatim (needs internet)

Dashboard refresh: Every 15 seconds

Allocation: Automatic (on every change + every 30 seconds)

Deleting: Resources and emergencies are soft-deleted, so history is kept.

This prototype displays records stored in its database. It does not receive real emergency-service feeds or live ambulance GPS positions.
