CrisisFlow is a Java-based disaster management project developed as part of our college PBL. It helps manage emergency reports, prioritize incidents and assign available resources.

FEATURES

Register emergencies such as floods, earthquakes, fires and accidents.
Assign priority based on emergency details.
Allocate available resources like ambulances, rescue teams and medical teams.
Track emergency and resource status.
View emergency locations on a map.
Support resource reassignment based on proximity.
Provide notifications and route information.

TECHNOLOGIES USED

Language: Java
Database: MySQL
Build Tool: Maven
Frontend: HTML, CSS and JavaScript
Map: Leaflet and OpenStreetMap
Containerization: Docker

HOW TO RUN

Install Java, Maven and MySQL.
Create the database and configure the database credentials.
Set the required environment variables.
Open the project folder in the terminal.
Run:
mvn clean compile exec:java
